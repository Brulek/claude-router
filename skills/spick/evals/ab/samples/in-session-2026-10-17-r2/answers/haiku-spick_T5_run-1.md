一、备份范围
各 Mac:~/dev 全量(含未推送分支、未跟踪文件),排除 node_modules 等构建产物;另含 ~/claude-sync。
~/Documents(含 Obsidian 库)各 Mac 相同,只由一台主 Mac 备份,并关闭其"优化 Mac 存储"。
Windows:用户目录下的代码与文档。
密钥不进备份,另列清单。

二、频率
每日 02:00 增量(Mac 用 launchd,Windows 用任务计划程序),先查未推送提交并提醒。
保留:日7、周4、月12。

三、存储位置
3-2-1:原件+外置盘/NAS+异地加密云(如 Backblaze B2)。
各机统一用 restic(跨平台、去重、加密)。
GitHub 只算代码多一份;iCloud 是同步不是备份,误删会同步。
备份库不放 iCloud,以免损坏 git 仓库。

四、恢复演练
每月抽一个项目恢复到临时目录,git fsck 通过、能构建即合格。
每季度用新账户模拟整机恢复。
失败或48小时无新快照即邮件告警。

五、风险与取舍
restic 密码丢失即全丢:存密码管理器并留纸质副本。
文稿只靠一台 Mac,省空间,但它离线会断档,靠告警兜底。
排除依赖省体积,恢复后需重装。
异地云有月费,换来火灾、失窃可恢复。
