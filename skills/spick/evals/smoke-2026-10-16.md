## Caveats

- **Hooks are only partly measured.** The installed hook (`~/.claude/settings.json`) and agents on this machine come
  from the main checkout, not this worktree, and a subagent never receives a UserPromptSubmit hook anyway. So each run
  was given the text of this worktree's `scripts/triage-hook.sh` (run with an empty config dir and the eval's prompt)
  as its checklist. The real hook path, the dashboard mod's gate and guard, and the installed `deep` agent's new
  default effort were not exercised. Eval 10's medium effort came from the explicit Agent call, not the agent's default.
- **The Hint line read the sandbox path.** The sandbox lives under `.../worktrees/review-round-1-b8e17b/...`, so
  `triage_hint.py` also reported `review words (review)` and the judgement word `verdict` from the path. The routing
  was right anyway, but keywords inside file paths are a false-positive source worth fixing.
- **Eval 10, one gap against Step 7:** the label says `deep Opus (medium)`, not the version `deep Opus 5.5 (medium)`.
- One run per eval: no variance, so treat these results as a check that nothing broke, not as a measurement.
